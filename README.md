# nodejs-hw

Це домашнє завдання №1 з курсу Node.js (Express сервер).

## Функціонал

- Створення сервера на Express.
- Логування запитів за допомогою `pino-http`.
- Обробка маршрутів для нотаток (`GET /notes`, `GET /notes/:noteId`).
- Глобальна обробка помилок (404 та 500).
- Робота зі змінними оточення через `dotenv`.
