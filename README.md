# nodejs-hw

Це домашнє завдання №1 з курсу Node.js (Express сервер).

## Функціонал

- **CRUD операції**: Створення, читання, оновлення та видалення нотаток.
- **Пагінація та фільтрація**: Можливість отримувати нотатки частинами (page, perPage) та фільтрувати за тегами (`Personal`, `Work`, `Health`, `Todo`).
- **Текстовий пошук**: Повнотекстовий пошук за вмістом заголовків та тексту нотаток.
- **Валідація**: Сувора перевірка вхідних даних (Joi/Celebrate) та форматів MongoDB ObjectId.
- **Логування**: Детальне логування HTTP-запитів за допомогою `pino-http`.

## 🛠 Технологічний стек

- **Runtime**: Node.js
- **Framework**: Express.js
- **Database**: MongoDB (Atlas) через Mongoose (ODM)
- **Validation**: Joi, Celebrate
- **Environment**: dotenv (керування змінними оточення)
- **CORS**: Підтримка крос-доменних запитів
